# ComfyUI 模型下载：选对文件、放对目录

ComfyUI 是一个运行工作流的工具，**安装 ComfyUI 不等于下载好了图片或视频模型**。第一次生成图片时，先选好工作流，再按工作流要求下载模型，不需要一次装下所有权重。

## 01 · 从工作流反向确定要下载什么

1. 打开 [第一次生成图片](/comfyui/first-workflow)，在 ComfyUI 内选择基础**本地文生图**模板。
2. 查看模板的模型信息、文件名称、文件大小与下载说明。
3. 记录所需文件：可能是一个完整 Checkpoint，也可能分别需要扩散模型、VAE、文本编码器等。
4. 打开模板提供的**原始模型仓库**，查看许可证、文件名、版本和是否需要账号授权。
5. 再按安装方式把文件放入对应目录。

::: tip 第一次应选哪种模型？
如果只是确认安装成功，优先选择能在你这台机器上运行的**基础文生图模型**，避免第一次就选择多组件大型视频工作流。模型下载量只是磁盘占用；运行时内存要另外评估。
:::

## 02 · 模型目录如何区分

| 常见目录 | 放什么 |
| --- | --- |
| `models/checkpoints/` | 某些完整 Checkpoint 模型 |
| `models/diffusion_models/` | 独立扩散模型权重 |
| `models/vae/` | 对应的图像/视频 VAE |
| `models/loras/` | LoRA 权重 |
| `models/text_encoders/` | 文本编码器 |
| `models/controlnet/` | 相关 ControlNet 权重 |
| `custom_nodes/` | 自定义节点的**程序代码**，不是模型权重目录 |

**目录名称相同不意味着模型必然兼容。** 模板要求哪个文件，就按照它所使用的加载器选择目录。

## 03 · 找到当前 ComfyUI 真正使用的模型文件夹

- **Desktop：** 通过应用的设置查看实际配置的数据、模型路径。不要假设它与手动版相同。
- **Mac 手动版：** [手动安装教程](/comfyui/mac-manual)中的 `src/models/` 位于你自己选择的 ComfyUI 项目目录内。
- **Ubuntu 手动版：** 当前教程的 `src/models/` 在你的 `comfyui-local` 项目文件夹下。
- **Windows 手动版：** 当前教程的 `src\models\\` 在 Windows 对应的项目目录下。

如果你修改过模型根目录或使用额外模型路径配置，以**当前实例真实配置**为准。

## 04 · 国外 / 国内应该怎样下载？

**能够访问官方仓库：** 按模板提供的官方模型下载链接操作；单文件可以在 Files 页面下载，大模型或多组件建议用官方 `hf download` 工具。

**国内网络：** 能直连优先直连；受限时可根据网络条件使用**科学上网**访问上游官方模型仓库；也可以核对 ModelScope 是否有**完全匹配的具体模型**，或审慎使用第三方 HF 社区镜像。

完整方法（包括 macOS、Ubuntu 与 Windows 命令）请看 [国内外模型下载指南](/guide/model-download)。

::: warning 不要随便改文件名和文件结构
有些加载节点根据文件名查找模型，有些工作流还依赖 VAE、文本编码器或特定量化格式。不要把下载到的 Hugging Face 原版模型直接当成与 MLX 或其他 ComfyUI 节点完全兼容。
:::

## 05 · 下载好之后如何验证？

1. 打开模型实际所在的文件夹，确认文件大小与发布仓库一致。
2. 回到 ComfyUI，刷新模型列表或根据提示重启。
3. 在工作流模型选择框中选择**实际存在的正确文件**。
4. 先生成一张低负载图片，确认输出目录出现可打开的文件。

如果仍出现“找不到模型”：先看是不是放在了另一个 ComfyUI 实例的数据目录，再核对模型类型、文件名和对应节点。

## 06 · 共用其他模型项目的权重

ComfyUI 支持配置额外模型路径；如果希望复用已有下载的模型，应先确认格式与节点兼容，再通过额外路径读取，**不要搬走其他已经部署成功的项目文件**。

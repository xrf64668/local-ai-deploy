# Mac 图像模型：使用 ComfyUI 生成第一张图片

<DeploymentSelection />

**你要完成的事：** 不写 Python 程序，通过图形界面选择工作流和对应模型，在自己的 Mac 上生成一张图片。

[← 返回 Mac 配置与任务选择](/mac/)

## 第一步 · 检查 Mac 配置

在「苹果菜单 → 关于本机」看 Apple Silicon 芯片和统一内存，在「系统设置 → 通用 → 储存空间」看可用空间。

**图像模型和视频模型不是同一条安装路线。** 同样叫 `safetensors` 的文件可能是 Checkpoint、UNet、VAE 或文本编码器，不能随便互换。ComfyUI 的显存/统一内存消耗也会受分辨率、精度与节点数量影响。

## 第二步 · 安装 ComfyUI Desktop

1. 打开 [ComfyUI 官方下载页](https://www.comfy.org/download)。
2. 选择 macOS Desktop 安装包，按照应用向导安装。
3. 打开软件，让应用完成基础环境准备。

**成功标志：** ComfyUI 的节点画布能打开。下载和模型载入可能需要网络，不代表此时已经能出图。

::: details 想手动控制 Python 环境和模型缓存？
只有在需要自定义插件、运行时或隔离依赖时，才阅读 [ComfyUI Mac 手动安装](/comfyui/mac-manual)。第一次使用推荐 Desktop，不必先学习终端。
:::

## 第三步 · 从官方工作流选模型

在 ComfyUI 中打开**模板 / 工作流**入口，优先从适配当前版本的**基础文生图模板**开始。打开模板的模型需求说明，核对所需权重、VAE 和文本编码器；如果界面提示下载缺少的模型，按照所选模板完成。

**不要直接下载最高参数量的 FLUX 或任意 SDXL 文件。** 首次运行优先选资源要求较低的基础流程；模板支持什么模型，下载什么模型。下载来源和存放目录以**当前工作流的实际模型需求**为准；Desktop 向导显示的位置优先，不必先跳到另一篇文档。

## 第四步 · 生成第一张图片

1. 打开准备好的文生图工作流。
2. 输入简单提示词，例如「一艘纸船漂浮在湖面上，柔和的晨光」。
3. 先使用模板自带的基础分辨率，再点击执行队列。
4. 生成成功后在 ComfyUI 输出区域找到图片并保存。

**成功标志：** 得到实际可打开的图像文件，而不是节点全绿或仅显示模型加载成功。

## 第五步 · 遇到错误怎么办？

如果提示缺少模型，请按工作流要求确认文件名称与目录。内存不足先换更小的工作流和分辨率，不要盲目增加复杂插件。

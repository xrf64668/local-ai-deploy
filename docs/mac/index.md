# Mac 本地 AI：按你的电脑和目标开始

**先看自己的 Mac 配置，再选一种想运行的模型。** 聊天、生成图片、生成视频和语音识别使用不同的工具；新手不用按顺序安装所有环境，也不用先理解 HTTP API。

<MacGoalAdvisor />

## 这四条路线有什么区别？

| 你的目标 | 使用的工具 | 第一次完成的标志 |
| --- | --- | --- |
| [语言模型](/mac/chat) | Ollama，管理聊天/代码模型 | 问一句话，模型回答 |
| [图像模型](/mac/image) | ComfyUI Desktop + 对应工作流 | 在本机保存一张图片 |
| [视频模型](/mac/video) | LTX 或 Wan 各自的 MLX 运行时 | 生成一段能播放的 MP4 |
| [语音识别](/mac/audio) | whisper.cpp + GGML 权重 | 把自己的语音转为文字 |

::: tip 第一次使用，应该从哪里开始？
先完成上方的三步选择，然后点击生成的**专属教程**链接。每篇只包含该类型的硬件条件、安装工具、查找和下载模型、首次运行、成功检查。**HTTP API 是额外功能，不是部署的必经步骤。**
:::

# Mac 视频模型：先选 LTX 或 Wan，再分别部署

<DeploymentSelection />

**你要完成的事：** 用 Apple Silicon Mac 生成第一段短视频。视频模型权重更大、依赖更特殊，不能把 LTX、Wan 和 ComfyUI 的安装命令混在一起。

[← 返回 Mac 配置与任务选择](/mac/)

## 第一步 · 先确认统一内存和磁盘空间

从 Mac 入口进入时，你的芯片、内存和可用磁盘已显示在本页上方，无须重新填写。请按下面的模型列表**只选一个**，然后在对应的完整教程中连续完成安装。

**这里只做容量初筛，不提前保证生成成功。** 下载文件大小、实际内存峰值和生成速度是三种不同指标；是否成功仍以你自己的 Mac 实测为准。

## 第二步 · 只选一个模型

| 模型路线 | 下载量级 | 参考起点 | 进入独立教程 |
| --- | --- | --- | --- |
| **LTX-2.3 MLX Q4** | 约 12GB | 上游低内存参考可从 16GB 尝试 | [LTX-2.3 完整部署](/mac/models/ltx23) |
| **LTX-2.5 MLX Q4** | 约 42–47GB | 32GB 以上先尝试低负载，另留较大磁盘空间 | [LTX-2.5 完整部署](/mac/models/ltx25) |
| **Wan2.2 TI2V-5B MLX Q8** | 约 19.6GB | 32GB 仅作为实验性起点；64GB 有上游样本 | [Wan2.2 完整部署](/mac/models/wan22) |

**一定要先选定模型再操作。** 上述 MLX 权重是针对特定运行时转换的版本，原版 PyTorch 权重不能直接替换使用；也不能把「文件大小小于 32GB」当成稳定运行保证。

## 第三步 · 进入对应模型的独立安装教程

### 路线 A：LTX 视频

使用 LTX 对应的 MLX 权重和 `ltx-2-mlx` 推理框架。

[开始：LTX-2.5 从选择文件夹到生成 MP4](/mac/models/ltx25)

教程里会依次完成项目目录、独立环境、权重下载、运行时安装和低负载生成；**不需要安装 Wan 或 ComfyUI**。

### 路线 B：Wan 视频

使用 Wan2.2 的专门 MLX Q8 权重和 `mlx-video` 工具。

[开始：Wan2.2 从权重下载到生成 MP4](/mac/models/wan22)

Wan 的 VAE、T5 文本编码器和生成参数与 LTX 不同。请使用 Wan 文章自己的下载和推理命令，不要交叉复制。

## 第四步 · 怎么判断自己成功？

在对应项目的 `outputs/` 文件夹找到实际 MP4，能打开播放；如已安装 FFmpeg，可以通过 `ffprobe` 检查时长和大小。只下载权重、CLI 能打印帮助或 HTTP 服务能启动，都不等于模型真实生成成功。

## 第五步 · 想让 Java 或其他程序调用？

**先完成 CLI 真实生成，再考虑 API。** 目前本站为 LTX-2.5 提供 [本地 HTTP 三步教程](/mac/models/ltx25-api)；Wan 的独立 HTTP 适配仍未完成，不能套用 LTX 的接口状态。

::: details 进阶：为什么不把这些模型装在一个 Python 环境？
LTX 的 `ltx-2-mlx`、Wan 的 `mlx-video` 与 ComfyUI 的 PyTorch MPS 依赖并不相同。共享一套可变依赖容易造成版本冲突。本站各模型专项都要求用户自己选择独立项目目录；模型、缓存、环境和输出保留在对应项目内。
:::

# 模型容量计算与部署建议

先选择平台和模型任务，再填写内存、量化、上下文等参数。**在下面选择 Mac、Ubuntu 或 Windows，填写内存、显存、模型量化和上下文长度。** 页面会实时估算权重、KV 缓存、推理工作区及设备预算，先在 Qwen3.8、Gemma、DeepSeek、gpt-oss、Llama、Mistral 等真实 Ollama 标签中筛选，再按预算展示适合进一步尝试的候选，而不是简单按固定门槛筛选。

## 应该怎样使用结果？

1. 看估算总量是否超过当前内存预算，接近上限时保守选择。
2. 对照实际模型文件、运行时、量化格式和许可证。
3. 完成一次真实推理，记录实际内存峰值、耗时与结果。

::: warning 计算不等于实测
跨厂商模型采用真实 Ollama 标签下载量加保护性余量进行初筛；传统 Qwen2.5 可单独展开权重、KV 缓存和工作区计算。视频模型会根据系统、内存/显存与磁盘给出具体的 LTX/Wan 候选，并标明上游依据和实验性状态，但**不把这些门槛当成实测峰值**。图片和语音暂提供实际部署入口。模型是否真正可用仍须在本机验证。
:::

# 看懂安装教程：新手术语词典

第一次安装 AI 工具时，最难的往往不是操作，而是不明白那些英文到底是什么意思。这里把常见词翻译成日常语言。

## 一张表先看懂

| 术语 | 简单解释 | 第一次安装要掌握吗？ |
| --- | --- | --- |
| 终端（Terminal） | 用文字告诉电脑做事的工具，类似输入指令的窗口 | 图形安装不用 |
| 命令（Command） | 让电脑完成某个动作的一行文字 | 手动安装才需要 |
| Git | 记录和获取程序代码的工具 | Desktop 不用 |
| `git clone` | 从网上复制一份开源程序到本机 | Desktop 不用 |
| Python | 很多 AI 工具使用的编程语言 | Desktop 通常无需手动安装 |
| `pip` | 给 Python 安装功能包的工具 | 手动安装需要 |
| 虚拟环境（`venv`） | 给某个项目分配一套独立 Python 依赖，不和其他项目混在一起 | 手动安装需要 |
| `source .../activate` | 让当前终端使用项目自己的 Python 环境 | 手动安装需要 |
| `cd` | 在终端中进入文件夹 | 手动安装需要 |
| `mkdir` | 新建文件夹 | 手动安装需要 |
| `export` | 设置当前终端后续程序使用的环境变量 | 进阶 |
| 统一内存 | Mac CPU/GPU 等共享的一块内存 | 选模型前要知道 |
| 显存（VRAM） | GPU 用来存放模型与计算数据的内存资源 | 选模型前要知道 |
| Metal / MPS | Apple GPU 计算能力与 PyTorch 在 Mac 上的对应后端 | 知道名称就够 |
| CUDA | NVIDIA GPU 常用计算平台 | Mac 新手不用 |
| MLX | Apple Silicon 常用的另一套机器学习运行时 | 使用专用 MLX 模型时才需要 |
| Checkpoint | 某类模型权重文件，类似模型的“知识和参数” | 下载模型时需要 |
| LoRA | 在原有模型基础上调整风格/能力的额外权重 | 进阶 |
| VAE | 负责将模型的潜空间表示与图片/视频数据转换的组件 | 工作流提示时再学 |
| 工作流 | 把一个个功能节点连接起来完成生成任务的操作流程 | 必须知道 |
| API | 让网页、程序或手机应用调用模型服务的接口 | 以后想开发才需要 |

## 终端最容易看错的三件事

### 1. 一个代码框里有很多行，不表示它们是一个命令

按教程给出的顺序逐行运行。**一旦某一步报错，应停下来先排查，不要继续粘贴后面几十行。**

### 2. 示例路径不是所有人的实际路径

例如 `/path/to/model` 是需要替换的示例。**直接复制它并不能找到模型。** 本站优先使用项目相对目录，减少手工填写个人用户名。

### 3. “命令运行没有报错”不是“模型成功生成”

要分成三个验收：程序安装完成 → 服务能启动 → 用真实模型成功输出文件。最后一步通过才算验证了推理。

### 如何判断部署结束？

- **语言模型：** 输入问题，真正得到回答。
- **图像模型：** 保存一张能打开的图片。
- **视频模型：** 生成一段可播放的 MP4。
- **语音识别：** 音频确实被转写为文字。

如果你已经熟悉模型部署，需要深入研究容量计算或新模型来源，可以单独使用 [容量计算器](/recommend/) 和 [官方模型搜索](/guide/model-search)。**新手无需从这些页面来回跳转。**

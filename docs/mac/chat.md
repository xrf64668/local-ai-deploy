## 01 · 检查自己的 Mac

在「苹果菜单 → 关于本机」确认 Apple Silicon 芯片与统一内存，系统设置中查看可用磁盘。如果从入口选过配置，上方会显示你填写的数据。模型容量是参考估算，不保证性能或实际峰值。

## 02 · 从官方安装 Ollama

1. 打开 [Ollama 官方 macOS 下载](https://ollama.com/download/mac)，安装并启动应用。
2. 在 Mac「终端」中执行：

```bash
ollama --version
```

**成功标志：** 输出 Ollama 版本号。找不到命令时先检查应用安装和启动状态，不需要安装 Python 或 ComfyUI。

## 04 · 遇到问题直接在这里处理

| 情况 | 接下来怎么做 |
| --- | --- |
| `ollama: command not found` | 确认 Ollama 已安装，重新打开终端 |
| 下载失败或中断 | 检查官方模型标签、剩余磁盘和网络；官方源受限时可根据网络条件使用科学上网 |
| 模型下载了却无法运行 | 关闭其他占用内存的程序，选一个更小的量化模型；下载大小不等于内存峰值 |
| 启动成功但没有回复 | 查看 Ollama 日志与内存压力，不能把服务启动当成推理成功 |

**完成标准：** `ollama list` 有目标模型、`ollama run` 能回答你的问题。做到这里即可，不需要再配置 HTTP。

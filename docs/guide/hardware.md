# 先看懂硬件：内存、显存和模型

选模型前先记住：**内存越大，通常可尝试的模型越多；但能不能运行还取决于运行时和模型格式。**

## Mac 和 NVIDIA 电脑有什么区别？

| 设备 | 主要内存形式 | 需要注意 |
| --- | --- | --- |
| Apple Silicon Mac | **统一内存**：CPU 与 GPU 共享 | 不能把全部内存都当作模型可用空间 |
| NVIDIA 显卡电脑 | **显存（VRAM）** + 系统内存（RAM） | 显存不足时，有些运行时能部分转移到内存，但可能变慢 |

例如，同样标着 16GB 的 Mac 统一内存与 NVIDIA 16GB 显存，**不能直接认为运行效果相同**。

## 除了内存，还要看什么？

- **模型大小与量化：** Q4、Q8、FP16 等格式会改变文件大小、资源占用及效果。
- **推理工具：** Ollama、MLX、ComfyUI 使用的权重不一定能互相直接加载。
- **任务设置：** 图片尺寸、视频帧数、语言模型上下文长度都会影响资源需求。
- **系统与驱动：** Mac 需关注 macOS、Metal/MPS；NVIDIA 需关注驱动和 CUDA 兼容性。
- **磁盘空间：** 除了模型，还要留出依赖、缓存与生成文件的空间。

## 怎样开始选模型？

先用 [硬件推荐器](/recommend/) 找到候选，再打开对应的安装教程。推荐结果只是**初步筛选**，最终以实际推理输出为准。

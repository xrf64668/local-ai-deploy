# 模型容量计算与部署建议

先选择平台和模型任务，再填写内存、量化、上下文等参数。**在下面选择 Mac、Ubuntu 或 Windows，填写内存、显存、模型量化和上下文长度。** 页面会实时估算权重、KV 缓存、推理工作区及设备预算，把 0.5B–72B 模型按可用预算分为优先推荐、可以尝试、谨慎尝试和容量不足，而不是简单按固定门槛筛选。

## 应该怎样使用结果？

1. 看估算总量是否超过当前内存预算，接近上限时保守选择。
2. 对照实际模型文件、运行时、量化格式和许可证。
3. 完成一次真实推理，记录实际内存峰值、耗时与结果。

# 第一次找模型：搜索、核对、下载

**不知道模型在哪？** 不用先学命令。按这里的三步操作，就能找到原始模型仓库，并根据自己的系统查看下载方法。

## 01 · 输入模型名字，找到原始仓库

例如输入 `Qwen3.8`、`LTX-2.5` 或 `Wan2.2`，然后点击搜索。搜索会实时向 Hugging Face 公开模型目录查询，不是从固定的演示名单里猜结果。

## 02 · 选对版本，再决定下载

点击结果中的「看模型官方仓库」，重点看三处：

| 仓库页面 | 新手重点检查什么 |
| --- | --- |
| 发布者和模型介绍 | 是官方发布、被认可的转换仓库，还是未经审核的上传？ |
| Files and versions（文件列表） | 权重是 `MLX`、`GGUF` 还是 `safetensors`？是否需要 VAE、文本编码器？ |
| 文件体积和许可证 | 磁盘空间是否足够？是否需要登录或接受使用条款？ |

**不同权重不能混用：** Ollama 文字模型通常从自己的模型库拉取；Mac 原生 MLX 使用适配 MLX 的权重；ComfyUI 需要与节点和工作流匹配的模型文件。

如果完全不知道该选哪个仓库，推荐先进入 [根据设备选择已审核模型](/guide/deploy)，而不是从陌生仓库里随便下载几十 GB 的文件。

## 03 · 生成自己的下载指令

搜索结果的「查看下载方法」提供一个**未经兼容性验证的 Hugging Face 下载示例**。只有你确认了具体仓库、模型格式、运行时及许可后，它才会显示 Mac、Ubuntu 或 Windows 对应命令。

代码会使用**你自己选择的专用文件夹**，不写死作者的用户名和模型路径。安装和下载工具都在项目文件夹内，下载结果会存到 `models/` 子目录。

**下载成功 ≠ 模型能运行：** 下一步仍需按照所选模型对应的运行时教程加载并完成首次生成。

[看国内外下载渠道的入门说明](/guide/model-download) · [进入按硬件推荐的模型目录](/recommend/)

::: details 进阶：为什么不把实时搜索结果直接推荐给所有人？
搜索接口只能证明仓库存在，不能保证它是官方发布，也不能证明文件结构、量化版本、许可证、后端适配或 GPU 资源足够。

本网站将「实时搜索发现」与「核对后的容量初筛」分开。想要加入正式推荐库，需要核对模型来源、发布版本和支持的后端；真实兼容性还要靠有证据的本地运行记录。
:::

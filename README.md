# 本地 AI 模型部署指南 · local-ai-deploy

基于 VitePress 的开源中文文档站，面向 Mac Apple Silicon、Ubuntu NVIDIA GPU、Windows NVIDIA GPU 的本地模型部署与硬件选型。

## 本地开发

- Node.js 22 或以上
- `npm ci`
- `npm run docs:dev`（本地开发）
- `npm run docs:build`（静态构建）
- `npm run docs:preview`（本地预览）

## 主要栏目

- 入门与硬件基础
- [根据硬件配置推荐模型](./docs/recommend/index.md)
- Mac、Ubuntu、Windows 实践

> 推荐器展示的是参考候选方案，不构成对性能、兼容性或模型许可证的保证。

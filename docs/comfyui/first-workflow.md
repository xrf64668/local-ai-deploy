# ComfyUI · 第一次生成图片（完全新手版）

这一篇只做一件事：**真正让电脑生成一张可以打开的图片。** 你不需要一开始就理解所有节点，也不需要编写 Python 程序。

如果 ComfyUI 还没打开，请先去 [Mac 零命令安装](/comfyui/mac)、[Windows Desktop 安装](/comfyui/windows) 或 [Ubuntu 安装](/comfyui/ubuntu)。

## 01 · 确认画布已经打开

打开 ComfyUI，你应该能看到一个可以拖动和缩放的工作区域。

这个区域叫**节点画布**。画布能打开，表示程序至少启动了，但**还不代表你的电脑已经具备生成图片的模型**。

**成功标志：** 主界面可操作，没有持续出现的启动错误。

## 02 · 找到现成的「文生图」模板

1. 打开软件内的 **工作流模板（Workflow Templates）** 入口；不同版本菜单名称和位置可能有所变化。
2. 找到一个明确标记为 **本地 Text to Image（文字生成图片）** 的基础模板。
3. 第一次不要选择需要账号、API Key、付费额度的 **Partner API** 工作流，也不要先用复杂视频、ControlNet、多 LoRA 工作流。
4. 加载模板后，不用自己画线，先看看节点有没有红色错误提示。

**成功标志：** 画布出现一组互相连接的节点，例如「加载模型」「输入文字」「生成图片」「保存图片」。

::: details 这一步为什么不用手动连接节点？
模板就像别人已经配好的一张流程图，初次使用只需要填文字、选模型、点运行。等你做出第一张图片，再理解每一条连线的意义。
:::

## 03 · 解决「模型文件缺失」

如果工作流提示缺失某个模型文件，先别继续点击运行。

1. 记下工作流提示的**完整模型文件名称**。
2. 打开该模板提供的官方模型说明，确认权重来源、大小、许可证和你当前电脑是否支持。
3. 如果界面支持按模板下载模型，就按其引导完成；否则按 [模型目录教程](/comfyui/models-and-paths) 把文件放入对应位置。
4. 回到画布，确认模型选择框能找到刚下载的文件。

**成功标志：** 工作流加载节点不再提示找不到模型。注意，模型文件存在还不代表一定能在你的 GPU 或统一内存里加载成功。

## 04 · 在哪里写提示词？

找到接受文字的节点，通常叫 **CLIP Text Encode** 或其他相似的文本输入节点（名称随模型而变化）。

可以先输入：

> A cozy wooden cabin in a snowy forest, warm light, beautiful illustration

意思是“雪林中的温暖小木屋，漂亮的插画风格”。你也可以换成自己想画的内容。

先不要修改太多参数，保留模板作者已经配置好的模型加载、采样器和解码节点。

## 05 · 点击 Run / Queue

1. 如果模板提供了分辨率和批量设置，首次尽量使用较小尺寸、一次只生成 **1 张**。
2. 找到界面的 **Run（运行）/ Queue（加入队列）** 按钮并点击。
3. 观察节点是否开始执行，等待输出预览，不要连续点很多次以免增加队列。
4. 如果出现红色错误信息，先读错误原因，再看 [ComfyUI 常见问题](/comfyui/troubleshooting)。

**成功标志：** 工作流完成，预览中出现图片，而不是仅显示排队中。

## 06 · 到哪里找生成结果？

ComfyUI 的输出位置跟**安装方式**有关：

- Desktop：使用应用设置里指定的输出/数据目录。
- 手动版：通常在该实例的 `ComfyUI/output/` 内。
- 不确定：先查看软件的工作流输出或存储设置，不要猜一个全局路径。

打开保存的图片，确认它不是空文件或错误截图。

::: tip 全部完成！
恭喜，你已经通过了三个不同的验证：**程序启动成功、模型配置正确、实际推理产生文件**。这才是完整的第一次生成。
:::

## 07 · 想知道每个术语是什么？

可以去 [新手术语词典](/comfyui/glossary) 学会 Checkpoint、LoRA 和 VAE，也可以继续 [ComfyUI API](/comfyui/api) 让其他程序调用你已经跑通的工作流。

需要长期可复现时，记录工作流文件、模型 revision、系统/GPU、生成参数和输出位置。

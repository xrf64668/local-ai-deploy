# 什么是本地 AI？

本地 AI，就是让模型主要在**自己的电脑或服务器**上计算，而不必每次都把内容发送给云端模型服务。

举个例子：你在 Mac 上安装 Ollama、下载一个文字模型，再输入问题，模型就能在本机生成回答。

## 本地运行有哪些限制？

模型文件可能占用数 GB 到数十 GB；运行速度取决于芯片、内存、显存及所选模型。下载成功并不等于能在当前硬件上正常推理。

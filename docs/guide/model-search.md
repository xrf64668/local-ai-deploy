## 推荐系统如何使用搜索结果？

**搜索发现 → 校验模型来源 → 核对权重格式与运行时 → 根据访客的配置评估 → 下载和真实测试**。

发现模型时首先检查模型作者、许可证、文件大小、revision、tokenizer、VAE、支持的运行框架，以及是否为原版或社区量化/转换版本。**实时搜索结果不会自动获得“已验证推荐”状态。**

::: tip 查询失败
如果网络无法访问 Hugging Face，浏览器会显示错误并提供官方网页搜索入口；必要时可按当前网络条件使用科学上网。本站不会把查询失败伪装成“无此模型”。
:::

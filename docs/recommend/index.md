# 模型容量计算与部署建议

先选择平台和模型任务，再填写内存、量化、上下文等参数。**在下面选择 Mac、Ubuntu 或 Windows，填写内存、显存、模型量化和上下文长度。** 页面会实时估算权重、KV 缓存、推理工作区及设备预算，列出初步可尝试的模型，而不是简单按固定门槛筛选。

## 应该怎样使用结果？

1. 看估算总量是否超过当前内存预算，接近上限时保守选择。
2. 对照实际模型文件、运行时、量化格式和许可证。
3. 完成一次真实推理，记录实际内存峰值、耗时与结果。

::: warning 计算不等于实测
公式针对传统自回归语言模型的容量估算，不预测推理速度，也不计算 CPU Offload、MoE 和多 GPU 场景。图片、视频和语音模型有不同的工作流与内存规律，目前提供实际部署入口，不以语言模型公式伪造“精确适配”。
:::
